## About
Code Vein 2 Character Builder is an unofficial companion app to the game,
meant to assist with build making and build sharing.

## Installation and starting the Builder

#### .exe (recommended for Windows users)
Download the latest release from Releases and run it.

#### .py
1. install PyQt6
```
pip3 install pyqt6
pip3 install pyside6
```
2. download or clone the repo
3. then run with
```
python main.py
```
