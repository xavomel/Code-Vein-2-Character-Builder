## About
Code Vein 2 Character Builder is an unofficial companion app to the game,
meant to assist with build making and build sharing.

## Installation and starting the Builder

#### .exe (recommended for Windows users)
Go to [Releases](https://github.com/xavomel/Code-Vein-2-Character-Builder/releases) page.<br>
Download the latest release (not the source code!) then extract it and run.

#### .py
1. install PyQt6
```
pip3 install pyqt6
pip3 install pyside6
```
2. download or clone the repo
3. then run with
```
python main.py
```

## Changing resolution
Coming soon in v0.5.3.<br>
High resolution mode (for 3840x2160 or similar) can be enabled by editing config.json:
```
"HighResolution": 0
```
replace 0 with 1 and restart the Builder.
